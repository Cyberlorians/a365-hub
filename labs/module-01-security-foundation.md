## Before you start

1. Open the slides in a modern browser. Start at **slide 6**.
2. Keep this guide and a blank copy of the worksheet below beside the slides.
3. Use **Next**, **Previous**, or **Jump** to move. **N** opens presenter notes.
4. Confirm the facilitator's mode:
   - **Content review:** no account, sign-in, portal, or tenant action. The published
     fictional Project Beacon card is a teaching example, not inventory/evidence.
   - **Prepared presentation:** watch a verified, authorized presenter view or labeled
     prior-run evidence. You still do not need admin roles.
5. If approved event onboarding is being delivered, follow slides 1-5 and the admin's
   event-specific instructions first. Do not use an old event link or share a TAP.
   This deck has no active signup link. Skip onboarding entirely during content review.

## Four-question worksheet

Use "not provisioned", "unknown", or "not observed" where appropriate. In content review,
do not turn the fictional card into a claimed real registration, receipt, or policy test.

| Question | Your answer |
|---|---|
| What agent/purpose? | |
| Who is the technical owner and accountable sponsor? Who actually acts? | |

| What happened? What evidence and next decision? | |
| Evidence mode: synthetic example / verified prior run / current run / missing | |
| One relevant control and what has actually been verified | |
| One gap, next action, and responsible role | |

## Check and finish

1. Complete slide 16; then compare with the
   [four-point answer key](../slides/module-01/exercise.md).
2. If you miss the dual-plane question, revisit slide 9 and explain it in your own words.
3. Finish the worksheet with one evidence-backed next action or an explicit open gap.
4. Open [Module 2](https://cyberlorians.github.io/a365-hub/module-02/#slide-1).
   Do not begin its live steps without the admin's go-ahead.

## If something does not work

| Problem | What to do |
|---|---|
| You land on onboarding | Use **Start Module 1 core** or Jump to slide 6 |
| A portal/view is unavailable | Tell the facilitator; use the stated review mode, not a new admin role |
| No activity/evidence exists | Record missing coverage; do not conclude the agent is safe |
| A real account/TAP is requested during content review | Stop; no tenant sign-in is needed for review |
| Someone exposes credentials or production content | Stop sharing and notify the responsible admin; do not copy it into the worksheet |

This module performs no tenant changes and has no learner cleanup command. Keep or
dispose of worksheets according to the event's data policy. Identity, permissions,
sources, and later controls are described in the [master plan](../docs/06-customer-learning-plan.md).
