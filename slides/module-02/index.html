Proposed activity / Only after approved lab setup

Review. Request send. Verify receipt.

  1. Check the message against the brief.
  2. Confirm the real approved internal test recipient.
  3. Explicitly request sending the reviewed message.
  4. Verify actual receipt, sender, subject, and time.
A draft, a healthy container, or a successful HTTP response is not proof of mail delivery.

If the result is uncertain, check for receipt before retrying. Do not duplicate sends or widen permissions to recover.
